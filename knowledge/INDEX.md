## Come cresce questo sistema

Ogni volta che:
- **Estraggo un engagement** → entry anonimizzata in `client-intelligence/insights/` + voci `lexicon.md` (LEVA #1)
- Un pattern emerge su ≥3 clienti → si valuta in `client-intelligence/patterns.md`, poi (review 3-6 mesi) affina `foundation/`
- Un engagement produce un risultato misurabile → riga in `proof-library/results.md`
- Analizzo un autore → si aggiunge una voce in `references/`
- Pubblico un pezzo → si aggiunge una voce in `posts/published.md`
- Osservo un pattern inatteso → si aggiunge in `craft/writing_techniques.md` (sezione False Beliefs)
- Edito una bozza → `craft/edit-patterns.md` registra cosa ho cambiato
- Nasce un'ipotesi → si aggiunge in `hypotheses/active.md`
- Un'ipotesi si conferma 3 volte → diventa regola in `platforms/[platform]/rules.md`

**Principio guida:** la sostanza (`foundation/`) cambia in un posto solo (il master) e si propaga.
La forma (`craft/`, `references/`) impara dall'evidenza. Il sistema non è completo: è un organismo vivo.
